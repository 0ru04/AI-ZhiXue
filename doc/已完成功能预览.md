# AI智学功能实现

本文档依据当前项目源码整理，按“核心 MVP”和“用户系统扩展”两个阶段归纳已经实现的功能。核心 MVP 的主流程在扩展阶段保持不变，扩展阶段主要补齐用户身份、云端持久化和历史回看能力。

## 一、核心 MVP 已完成，扩展阶段不改

1. **文本输入与内容安全过滤**：首页支持输入一句话或一段文本，长度限制为 500 字；后端对输入内容和 AI 生成内容执行敏感词过滤，模型未配置、调用超时或输出不合格时返回明确错误，不生成假题目。
2. **AI 生成固定 5 道题**：3 道单选、1 道多选、1 道判断。后端使用结构化输出和 Pydantic 校验，确保题目数量、题型比例、选项、答案、知识点、难度和讲解字段完整有效。
3. **逐题作答、即时讲解和本地反馈**：支持单选、多选、判断题，逐题提交后立即展示答对或答错状态、正确答案、本题 XP、连击和可折叠知识讲解。
4. **XP 和知识币**：服务端重新判题、正确率、连击、XP 和知识币计算。后端根据题目答案重新判定结果，不采信客户端提交的正确性；完全正确获得 20 XP 和 3 知识币，多选仅漏选且无错选获得 10 XP，答错不扣 XP。
5. **AI 学习复盘报告生成**：报告返回正确率、答对题数、最高连击、总用时、掌握点、薄弱点、三句知识总结、复习建议和分享金句；统计数据由服务端计算，AI 只负责生成复盘文字。
6. **当前闯关状态保存在小程序本地，可恢复当前一次闯关**：题目、当前题号、已选答案、答题记录、XP、知识币、连击和报告状态统一保存在本地 `RunState` 中，页面重新进入后可继续当前流程。
7. **分享海报 Canvas 生成、保存相册和微信转发**：海报包含学习主题、分享金句、正确率、答对题数和最高连击，支持保存到相册及微信好友分享；当前小程序码为明确标识的占位图。
8. **H5 与微信小程序双端基础工程**：前端使用 Taro 4.3、React 和 TypeScript，共用首页、闯关页、报告页及核心 API；H5 保持匿名学习流程，微信小程序额外启用用户系统页面。

其中分享海报虽然曾在文档中列为后续能力，但核心 MVP 已经实现，因此扩展阶段不再改造海报生成和分享主流程。

## 二、扩展阶段已完成

1. **数据库初始化**：新增 `users`、`quiz_sessions`、`answer_records`、`reports` 四张业务表，并保留 `alembic_version` 迁移版本表；使用 MySQL、SQLAlchemy asyncmy 和 Alembic 管理表结构。
2. **微信登录接口**：实现 `POST /api/v1/user/login`，通过小程序 `Taro.login()` 获取 code，由后端调用微信 `jscode2session` 换取 openid；首次登录自动注册用户，成功后返回 JWT 和基础用户信息。
3. **JWT 鉴权**：实现 Bearer Token 解析；用户档案、用户历史列表和历史详情接口必须登录，出题与报告接口保持可选鉴权，匿名用户仍可完成核心学习流程，无效 token 不会被静默降级为匿名请求。
4. **前端自动登录**：小程序启动时执行静默登录，缓存 token；重复请求复用同一次登录过程，登录失败不阻断首页输入和核心闯关。
5. **API 请求鉴权**：统一请求层自动携带 token，处理 401 并清理失效登录态；出题和报告请求在登录失效时可自动改为匿名请求并继续完成当前流程。
6. **题目持久化**：出题成功后，已登录用户的 `quiz_id`、标题、摘要、原始输入和完整题目快照写入 `quiz_sessions`；匿名用户仍可正常出题，但不写入云端记录。
7. **答题与报告持久化**：报告生成后写入 `answer_records` 和 `reports`，并根据服务端统计更新用户累计 XP；同一 `quiz_id` 重复提交只更新本次记录，不重复累加 XP，同时校验闯关数据归属。
8. **用户档案接口**：实现 `GET /api/v1/user/profile`，返回昵称、头像 URL、累计 XP、完成闯关次数、累计答对题数和平均正确率。
9. **更新档案接口**：实现 `PUT /api/v1/user/profile`，支持修改昵称和头像 URL；昵称不能为空且不超过 100 个字符，头像支持 HTTP/HTTPS 地址或清空。
10. **个人中心页面**：新增“我的学习档案”页面，展示真实头像、昵称、累计 XP、完成闯关数、答对题数和平均正确率，并提供资料编辑、空历史、加载失败和重新加载状态。
11. **首页用户信息**：微信小程序首页新增真实用户卡片，展示头像、昵称和累计 XP；登录不可用或用户主动退出后显示匿名状态，不阻断继续学习。
12. **闯关历史列表**：实现 `GET /api/v1/user/quizzes?page=1&page_size=10`，按创建时间倒序分页返回标题、正确率、题目数和完成时间，页面支持继续加载更早记录。
13. **闯关详情接口**：实现 `GET /api/v1/user/quizzes/{quiz_id}`，返回本次闯关的完整题目、答题记录和报告；只能读取当前登录用户自己的已完成闯关，记录不存在或不属于本人时返回 404。
14. **个人中心历史列表**：在个人中心展示真实闯关历史，列表项包含标题、正确率、题数和完成时间；空历史时显示引导，不展示伪造记录。
15. **历史报告回看**：新增独立历史复盘页，通过 `quiz_id` 从后端读取云端快照，展示正确率、总结、掌握点、薄弱点、逐题作答和复习建议，不依赖当前本地 `RunState`。
16. **退出登录与匿名降级**：支持主动退出微信身份并进入匿名学习模式，账号和云端历史继续保留；用户可重新登录恢复档案和历史同步。
17. **测试与配置**：补充登录、JWT、匿名模式、数据落库、XP 幂等、用户数据隔离、档案统计、历史分页和历史详情等后端测试，并更新 `.env.example` 与 README；前端已通过 TypeScript 类型检查。

本次扩展阶段以用户系统一期为边界：首页“已完成关卡/最近历史”区域、头像文件上传和知识币云端累计尚未实现；历史回看采用独立的历史复盘页面，没有改造为报告页的本地/历史双模式。

## 三、第三阶段实现

本阶段范围由《项目总需求分析文档》扣除核心 MVP 和用户系统扩展阶段已经实现的能力得出。原需求文档中的 P1、P2、P3 优先级继续保留，但统一归入第三阶段建设范围。

### P1：输入扩展与学习留存

#### 输入扩展：
1. **PDF/Word 文档解析**：支持用户上传 PDF、Word 等文档，解析正文、标题和结构信息，并将文档内容用于出题和复盘。
2. **网页 URL 解析**：支持输入网页地址，抓取页面正文并过滤导航、广告等无关内容，再基于正文生成题目。
3. **视频链接解析**：支持输入视频链接，提取音视频内容、生成文字转写并提炼知识点，最终用于题目生成。

#### 知识扩展：
4. **联网检索与知识补充**：根据用户输入的主题调用搜索引擎或知识检索服务，获取外部资料后再生成题目。当前出题只使用用户直接输入的文本，没有联网补充知识。
5. **RAG 私有知识库**：支持创建、编辑和删除多个私有知识文件夹；支持上传、管理和检索知识库文档；使用向量数据库完成文本切分、向量化和召回，并基于私有资料生成题目和考试模拟。



## 四、更多扩展实现

6. **错题本**：自动记录历史错题、用户选项、正确答案、知识点和错误次数，支持按知识点、时间和错误类型筛选，并进行针对性重练。
7. **艾宾浩斯复习计划**：根据错题和薄弱知识点安排复习时间节点，到期自动生成“旧识重温”关卡，并提供复习提醒和掌握状态更新。
8. **学习数据分析**：在用户后台展示跨闯关的学习数据，包括闯关次数、学习时长、正确率趋势、知识点掌握度、薄弱点和近期变化，并以图表形式呈现。
9. **知识树**：按照知识领域、知识点和前置关系组织用户已学与未学内容，展示掌握、薄弱和待复习状态。
10. **跨历史深度复盘报告**：除当前单次闯关报告外，汇总多轮历史数据生成阶段性学习总结、知识结构分析、薄弱点排行和后续学习建议。

### 社交与多模态

1. **微信好友双人 PK**：支持邀请微信好友进入同一知识主题的对战房间，完成同题作答、实时进度同步、双方成绩结算和胜负展示。
2. **知识领域排行榜**：按知识领域维护全服排行榜，展示用户排名、正确率、闯关次数或积分，并支持周榜、总榜等统计维度。
3. **题目 AI 配图**：根据题目内容自动生成或选取示意图片，并应用到题干、选项或讲解中。
4. **语音对答与数字人播报**：支持题目语音播放、语音作答、语音讲解和数字人播报，形成文本之外的多模态学习交互。

### 商业化与 B 端

1. **VIP 订阅**：提供基础会员权益、订阅购买、续费和会员状态管理。
2. **高级 AI 解析包**：提供高级文档解析、深度分析和更大额度 AI 能力，并按解析包类型控制可用功能。
3. **大文档按量付费**：针对超大文档或高频解析场景，按照解析次数、页数或 Token 用量计费。
4. **B2B 定制套餐**：面向企业培训和机构考核提供独立知识库、成员管理、题库生成、考试管理和定制服务。
5. **支付与权益体系**：建立订单、支付、退款、订阅状态、额度扣减和功能权限校验，为 VIP、解析包、按量付费和 B2B 套餐提供统一支撑。
