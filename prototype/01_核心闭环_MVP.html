第 01 章

一条最短的学习闭环

MVP 不做题库管理、不做用户中心、不做排行榜。只把一件事做到顺滑：用户输入一个知识点，AI 印出 5 道题，答完立刻讲解，通关后给一份能带走的复盘。

01 / INPUT

说一句

一句话或一段文本；空输入禁用提交。

02 / PRINT

印成题

3–8 秒生成 5 题；失败保留输入可重试。

03 / PLAY

闯一话

一屏一格；选择后交卷，立刻看对错和讲解。

04 / CLEAR

盖个章

通关结算：正确率、XP、知识币、这一话带走什么。

05 / REVIEW

收个尾

复盘报告 + 无排名分享海报。

第 03 章

状态覆盖：加载、空、失败、成功

MVP 也必须把状态做全。尤其是 AI 产品：等待和失败是常态，不能让用户看到白屏、假数据或技术报错。

LOADING

加载

生成中显示三层纸叠 + 4 步进度 + 骨架屏；禁用重复提交；3–8 秒内有明确进度感。

EMPTY

空

输入为空时主按钮禁用；示例 chips 兜底；不展示空白页。没有历史记录时不硬塞“空档案”。

ERROR

失败

生成失败保留输入；报告失败保留答案；只给“重试 / 返回”，不展示半成品题目或虚构报告。

SUCCESS

成功

即时反馈 → 通关结算 → 复盘报告 → 分享海报。每一步都有明确的下一步动作。

第 04 章

关键交互规范

给前端和 AI 后端的对齐清单。每一条都能直接落到 Taro 页面或 FastAPI 接口里。

输入 / Input

  • 单次输入上限 500 字；空输入时主按钮禁用。
  • 点击示例 chip 自动填入并聚焦输入框。
  • MVP 不登录；生成记录只存本机，不上传用户身份。

生成 / Generate

  • 调用 POST /api/v1/quiz/generate，默认 5 题。
  • 生成中禁用重复提交；显示 4 步进度；支持取消。
  • 失败保留输入；重试不重复扣次数；不展示脏数据。

答题 / Quiz

  • 一屏一题；单选 / 多选 / 判断三种题型。
  • 选择后交卷；提交后锁定该题；立即展示对错与讲解。
  • 讲解可折叠；答错不扣 XP，只少拿 XP。

结算 / 报告

  • 前端本地统计正确率、用时、连击；一次性提交答题记录。
  • 报告失败保留答案；重试只重新生成报告。
  • 报告字段：正确率、掌握点、薄弱点、三句总结、建议、金句。

海报 / Share

  • 海报不含排名，只展示正确率、答对数、最高连击。
  • 保存 / 分享两个动作分开；小程序码为占位。
  • 若工期紧，可把海报后置到 P0 尾或 Phase 5。

视觉 / Visual

  • 正文 15–16px、行高 1.7；题目字号 ≥ 20px。
  • 点击区 ≥ 44px；对错用颜色 + 图标 + 文字三重编码。
  • 漫画装饰只出现在反馈 / 奖励 / 空态；不干扰题目阅读。
