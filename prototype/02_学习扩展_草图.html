第 01 章

从“学过一次”到“记得住”

P1 不新增学习入口，而是把 MVP 产生的数据接住：每一话进书架，错题进错题本，薄弱点进复习计划，外部资料进知识库。目标是把一次性闯关变成可回访的学习档案。

进书架

02 / DIAGNOSE

看档案

03 / REVIEW

错题复习

错题本 + 1/3/7/15 天复习节奏。

04 / IMPORT

多源输入

文档、网页先解析；视频后置，再确认知识点。

05 / RAG

私有知识库

把资料变成专属题库，只引用选中范围。

第 03 章

P1 的空态与失败态

P1 页面比 MVP 更容易出现“空的”和“解析失败的”。这些状态不另做复杂页面，但必须在草图阶段定好文案和下一步动作。

EMPTY

空书架

还没有闯关记录：小墨说“书架空着，去印第一话吧”，主按钮回首页。

EMPTY

空错题本

“错题本还是空的”——不是坏事，给一个“去闯一话”的入口，不展示空白列表。

ERROR

解析失败

格式不支持 / 链接抓取失败 / 文档加密。说明原因 + 重试 + 换文件，不吞错。

EMPTY

知识库为空

“这个知识库还没有文档”，引导添加第一份资料；出题按钮禁用。

状态原则：空态给方向，失败态给原因和下一步；所有失败都要保留用户已经产生的数据（输入、答案、文档），不做“重新来过”式清空。
第 04 章

已确认的 3 个方向

以下方向已确认。P1 高保真将按“漫画书架 + 轻数据看板、文本/文档/网页首发、1/3/7/15 天复习”推进；视频解析后置。

Q1 / ARCHIVE

学习档案做成什么形态？

纯数据看板更效率；纯漫画书架更有产品性格；两者结合信息量最大，但首页更长。

已确认：漫画书架 + 轻数据看板
Q2 / INPUT

多源输入首发做到哪一步？

文本 + 文档最快；加网页会多一层抓取稳定性；全含视频体验最完整，但解析链路最重。

已确认：文本 + 文档 + 网页，视频后置
Q3 / REVIEW

复习节奏用哪套？

1/3/7/15 天更接近艾宾浩斯；1/3/7 天更轻；自定义最灵活但增加设置成本。

已确认：1/3/7/15 天，连续 3 次答对毕业
关于登录：P1 建议加微信登录，但保留“先不登录直接学”。MVP 仍可无登录运行；登录只用于同步书架、错题和复习计划。
