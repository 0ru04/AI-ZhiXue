第 01 章

把学习，做成一期漫画

市面上的学习产品把知识做成“游戏”，我们把它做成一期“漫画”。打开 AI 智学，像翻开一本新的《漫画Party》：输入一个知识点，AI 把它印成 5 格闯关漫画；答对盖章，答错小墨跳出来讲明白；通关后，这一话就收进你的学习档案。漫画是容器，学习闭环才是内容。

01 / INPUT

说一句

一句话、一段文本，或后面扩展的文档 / 网页 / 视频。

02 / PRINT

印成题

AI 提炼考点，生成单选、多选、判断，并附上即时讲解。

03 / PLAY

闯一话

一格一题，答对盖章，答错补课；XP 和知识币即时到账。

04 / REVIEW

收个尾

正确率、掌握点、薄弱点、三句总结，生成可分享的一话封面。

1

一屏一格，一格一动作

沿用漫画分镜的阅读节奏：一屏只回答一个问题，只留一个主动作。题目不被贴纸和进度条挤走。

2

反馈像盖章，不像弹窗

对错、XP、连击都用“盖章 / 贴纸 / 拟声词”表达，但正文解释保持干净，像漫画里的旁白框。

3

通关即档案，不是流水账

每一话都有封面、标签和一句金句。报告不是数据堆砌，而是“这一话你学会了什么”的合订本。

版权提示

本方案提取的是“猫式画风”的视觉语法：粗墨线、夸张表情、高饱和三色、校园幽默，不复刻阿衰、大脸妹等受版权保护的角色与封面。主视觉使用原创吉祥物「小墨」。如果你希望更强的“阿衰既视感”，需要另行确认 IP 授权；否则建议保持“神似不形似”。

参考拆解 / RESEARCH

参考了什么，放弃了什么

先看了市面上的同类产品和漫画风 UI 的通用做法，再决定哪些能借、哪些不能借。结论是：用多邻国的节奏、答题小程序的骨架、漫画 UI 的语法、阿衰的气质，拼成一个不冒犯 IP 的原创视觉系统。

第 02 章

六个视觉基因

不是把页面做成“漫画贴纸大礼包”，而是提取六个可复用的视觉基因。它们负责让产品一眼有阿衰的年代感，同时不牺牲学习工具的可读性。

粗墨线

01 · 手绘粗墨线

3–4px 描边，转角略不稳，像钢笔速写。所有面板共享同一条“墨线”，形成统一的手绘印刷感。

CMYK

02 · 三色套印

墨黑、朱红、铬黄、天蓝。关键卡片用“套印没对准”的硬阴影，像旧印刷机留下的错位。

网点纸

03 · 网点纸

低透明度网点只做背景和情绪，不铺在正文下面。它是纸张的呼吸，不是装饰的噪音。

04 · 分镜框

页面结构 = 漫画分镜。一屏最多两层框，避免“盒子套盒子”；留白就是格与格之间的 gutter。

答对啦!

05 · 拟声词与爆炸贴

只在反馈、奖励、通关出现。BAM、叮、噗——每次一个，不刷屏；它是情绪标点，不是正文。

已掌握

06 · 印章

正确、掌握、通关都用印章表达，形成可收集的成就语言。比“+10 分”更有记忆点。

要做 / Do

  • 把漫画感集中在反馈、奖励、进度、空态。
  • 正文保持 15–16px、行高 1.7，长解释用旁白框。
  • 对错同时用颜色、图标、文字三重编码。
  • 一屏只留一个主动作，拇指区放主按钮。
  • 每一话都有封面、标签和一句可分享的金句。

不要做 / Don't

  • 不要给每段讲解套爆炸框，阅读会被打断。
  • 不要大面积铺高饱和红/黄，纸感会被淹没。
  • 不要复刻阿衰、大脸妹等受版权保护的角色。
  • 不要让贴纸、旋转、网点干扰题目阅读路径。
  • 不要用排行榜和复杂个人中心挤掉核心闭环。

已确认的 4 个方向

以下方向已确认。最终 MVP 高保真原型见 01_核心闭环_MVP.html；02–04 作为后续扩展，不在本次范围。

Q1 / STYLE

漫画浓度要到哪一档？

浓漫画：分镜框、网点、拟声词、印章全上，最像翻漫画；轻漫画：干净 UI + 漫画点缀，阅读更稳；复古印刷：更克制的三色与纸张质感。

已确认：浓漫画，正文保持干净
Q2 / CHARACTER

要不要固定吉祥物？

原创「小墨」负责陪学、吐槽和讲题，能形成记忆点；无角色则更中性、更工具化；也可以换一个你更喜欢的原创形象。

已确认：原创小墨，规避 IP 风险
Q3 / SCOPE

这一套原型覆盖到哪？

只做 MVP 七页最快；MVP + P1 能看留存闭环；MVP + P1 + P2 是完整产品地图，但页面数量会明显增加。

已确认：仅 MVP（核心闭环 12 屏）
Q4 / AUDIENCE

主要给谁用？

全年龄泛学习：语气更克制、示例更广；中小学生：更夸张、更游戏化；大学生 / 职场：更效率、更知识管理。

已确认：全年龄泛学习，偏年轻用户
